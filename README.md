# Persianas & Cortinas Dany — Decoración con Estilo

Sitio web oficial, catálogo interactivo y galería de proyectos para **Persianas & Cortinas Dany**, ubicado en Granada, Meta (Barrio Montoya).

![Persianas & Cortinas Dany](public/favicon.svg)

---

## 🌟 Características Principales

- **Catálogo de Productos:** Exploración por categorías (Cortinas, Persianas, Estores, Accesorios) con búsqueda instantánea y fichas detalladas.
- **Galería Multimedia:** Fotos y videos de proyectos reales con reproducción silenciosa automática y visualizador lightbox.
- **Cotizaciones Directas:** Integración interactiva con WhatsApp a dos líneas comerciales (`312 355 8218` y `311 811 9520`) y botón flotante accesible.
- **Panel Privado de Administración:** Gestión de productos y galería con subida de archivos y recorte inteligente de fondo transparente en local mediante IA.
- **SEO Técnico & Rendimiento:** Metadatos dinámicos Open Graph, Twitter Cards, JSON-LD estructurado (`LocalBusiness` y `WebSite`), `sitemap.xml`, `robots.txt` y PWA Manifest.
- **Cumplimiento Legal:** Páginas integradas para Términos y Condiciones, Política de Privacidad (Ley 1581 de 2012 de Colombia - Habeas Data) y banner de consentimiento de cookies con almacenamiento local.

---

## 🚀 Tecnologías

- **Frontend:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Enrutamiento:** [React Router v7](https://reactrouter.com/)
- **Estilos:** Vanilla CSS moderno con sistema de diseño modular, tokens de color, glassmorphism y animaciones fluidas
- **Iconos:** [Lucide React](https://lucide.dev/)
- **Almacenamiento Local:** IndexedDB de alta capacidad para fotos/videos + LocalStorage
- **Procesamiento de Imágenes:** Recorte de fondo en el cliente con `@imgly/background-removal`

## 🛠️ Instalación y Desarrollo Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/Sagerman/Cortinas-y-persianas.git
   cd Cortinas-y-persianas
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```
   Abre [http://localhost:5173](http://localhost:5173) en tu navegador.

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
